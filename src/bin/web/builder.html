      How state icons work
      
        
      Pick a button on an activity page. Its current icon or text is the default look. Then drop an image (or type a label) for each state of a device, like ON or an input name. The button switches look within about 2 seconds of the change and goes back to its default when no state matches. What the button does when pressed doesn't change.
      
        
      Only activities with one page are offered: when a page of the activity on screen changes, the remote jumps back to that activity's first page, which would interrupt you on activities with more pages.

        Using them on the remote
        
        
        After saving, add the new entities to the integration (Integrations → Remote Self-Control → add entities). They're in the Remote Sliders & Menus group.
        
        
        Sliders are light entities. Put one on a home page: tapping the tile opens a slider pop-up. On a Remote 3 you can also assign it to the touch slider in an activity.
        
        
        Displays are media player entities: put a media player widget for one on any activity page. Its picture is a large level gauge that follows a number, with three lines of text; tapping the picture and the widget's list run your steps. They update live, also on activities with several pages.
        
        
        Quick menus are list entities. On a home tile or an activity page they open a list pop-up; picking a choice runs its steps. Steps run in the background, so they can't switch the remote's screen to another activity.
