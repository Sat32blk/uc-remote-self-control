Smart Controls Builder

Conditional buttons for the Remote Self-Control integration. Each button checks your devices or the remote, then runs the first branch that matches.

Log in

Enter the web-configurator PIN. Find it on the remote under Settings → Web configurator.

Save to the remote

No unsaved changes.

    After saving, add new controls to the integration (Integrations → Remote Self-Control → add entities) and to the activities that use them. Smart controls run in the background, so they can't switch the remote's screen to another activity.

    Last test

    Use a control's Test button to run it once on the remote.
