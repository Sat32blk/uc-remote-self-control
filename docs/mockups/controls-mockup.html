Remote Self-Control Builder

Controls: map the Control device's up/down to any buttons and the touch slider to it. Turning on a Control: <name> switch points them at something else.

This tab isn't part of this mockup. Open Controls ⇅.

How long a control stays on

When it ends, its switch turns off and Control goes back to the activity's defaults below. Turning on another control switches straight to it.

Defaults per activity

What Control does in each activity when no control is on. Pick Nothing if the buttons or slider should do nothing until a control is turned on.

Each control becomes a switch named Control: <name>.

Devices this adds to the remote

Add them to the integration and to your activities, then map them in the web configurator like any other device.
