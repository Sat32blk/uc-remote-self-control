Normal controls

What the controls do when no mode is active. The volume rocker keeps the activity's own mapping (smooth hold, the TV's real volume in the pop-up); the integration only takes it over while a mode is on. The touch slider stays on Control Level, which passes it on.

A mode points the controls at one of your sliders until it times out.

Set up an activity

Do this once per activity. The integration does the green steps itself.

  • ✓
    Include Control, Control Level and the mode triggers in the activity, and put the trigger buttons on the pageAutomatic. No Control widget is needed on the page.
  • ✓
    Vol + / Vol − stay on the TVAutomatic: the integration switches them to Control only while a mode is on, and back right after (also after a restart).
  • ✓
    Add the Control Level tile to the home page (tap it for the slider pop-up)Automatic
  • 1
    Set the touch slider to Control LevelDo this yourself once in the web configurator (activity → touch slider). The integration can't change this setting.

Try it

Tap 💡 Light or 🎚 Bass on the screen, then use the rocker, the touch slider or the home tile. Leave it alone and it goes back to normal.
